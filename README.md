# stpaul2coderdojo.github.io

Static GitHub Pages site for CoderDojo Rondo.

## Based on

The original CoderDojo Rondo WordPress site:
https://coderdojorondo.wordpress.com/

The redesign preserves the site's themes and selected archive topics while presenting them as a lightweight static site.

## Deploy

1. Create a GitHub repository named `stpaul2coderdojo.github.io`.
2. Upload the contents of this ZIP to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Visit `https://stpaul2coderdojo.github.io/`.

GitHub's user-site repository naming convention requires the repository to match the account name plus `.github.io`.
