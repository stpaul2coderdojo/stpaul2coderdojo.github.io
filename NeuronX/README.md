# NeuronX Website

Static landing page for NeuronX, an agentic neuroscience modelling application built around NEvents.

## Deploy to GitHub Pages

1. Create a GitHub repository named `NeuronX.stpaulcoderdojo.github.io` under the `stpaulcoderdojo` account.
2. Upload `index.html` and `README.md` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. The site will be available at `https://NeuronX.stpaulcoderdojo.github.io/`.

The **Launch NeuronX** buttons point to the supplied Google AI Studio app.
